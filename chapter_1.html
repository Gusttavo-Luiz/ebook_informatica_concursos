Conceito de Informática

A Informática é a área responsável pelo tratamento automático da informação por meio de computadores.

O termo deriva da junção de duas palavras:

  • Informação
  • Automática

Ou seja, refere-se ao processamento de dados de forma automática utilizando sistemas computacionais.

Nos concursos públicos, a informática costuma aparecer em três grandes áreas:

  • conceitos básicos de computação
  • hardware e software
  • internet e segurança da informação

Evolução dos Computadores

A evolução dos computadores é geralmente dividida em cinco gerações tecnológicas.

Primeira Geração (1940–1956)

Características:

  • uso de válvulas eletrônicas
  • computadores enormes
  • alto consumo de energia
  • baixa confiabilidade
  • Exemplo:
  • ENIAC

Segunda Geração (1956–1963)

Características:

  • substituição das válvulas por transistores
  • computadores menores
  • maior confiabilidade
  • menor consumo de energia

Terceira Geração (1964–1971)

Características:

  • uso de circuitos integrados
  • aumento da capacidade de processamento
  • surgimento de sistemas operacionais mais sofisticados

Quarta Geração (1971–Presente)

Características:

  • surgimento do microprocessador
  • popularização dos computadores pessoais (PCs)

Empresas importantes:

  • Intel
  • IBM
  • Apple

Quinta Geração (Atual)

Características:

  • inteligência artificial
  • computação em nuvem
  • processamento paralelo
  • computação quântica (em desenvolvimento)

Dados vs Informação

Uma distinção muito importante em informática é a diferença entre dados e informação.

Dados

Dados são valores brutos, ainda sem interpretação.

Exemplo:

  • 324528

Esses números isolados não possuem significado.

Informação

Informação é o resultado do processamento de dados, possuindo significado.

Exemplo:

A média de idade da turma é 32 anos.

Agora os dados foram interpretados e transformados em informação.

Resumo estratégico
Pegadinha de banca

Algumas questões trocam propositalmente os conceitos.

Dados não possuem significado isolado.

Somente após processamento se tornam informação.

Arquitetura de Von Neumann

A Arquitetura de Von Neumann é o modelo clássico de organização dos computadores modernos.

Foi proposta pelo matemático John Von Neumann em 1945.

Esse modelo define a estrutura básica de funcionamento de um computador.

Componentes da Arquitetura

A arquitetura de Von Neumann possui quatro componentes principais:

  • Unidade de Controle (UC)

Responsável por coordenar a execução das instruções.

Unidade Lógica e Aritmética (ULA)

Responsável por executar operações matemáticas e lógicas.

Exemplos:

  • soma
  • subtração
  • comparações
  • Memória
  • Armazena:
  • dados
  • instruções

Dispositivos de Entrada e Saída

Permitem interação com o usuário.

Entrada:

  • teclado
  • mouse
  • scanner
  • Saída:
  • monitor
  • impressora

Modelo de Funcionamento do Computador

O funcionamento do computador segue um ciclo chamado:

  • Ciclo de Instrução

Esse ciclo possui três etapas principais:

  • Busca (Fetch)

Decodificação (Decode)

Execução (Execute)

Busca (Fetch)

O processador busca a instrução na memória.

Decodificação (Decode)

A instrução é interpretada.

Execução (Execute)

A instrução é executada pela ULA.
