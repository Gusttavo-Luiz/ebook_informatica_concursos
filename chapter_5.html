Conceito de Hardware

Hardware é o conjunto de componentes físicos que compõem um computador.

São os dispositivos que podem ser vistos e tocados.

Exemplos de hardware:

  • processador (CPU)
  • memória RAM
  • placa-mãe
  • disco rígido (HD)
  • unidade de estado sólido (SSD)
  • teclado
  • monitor

Esses componentes trabalham juntos para permitir o funcionamento do sistema computacional.

📦 Resumo estratégico:
  • Hardware = parte física do computador
  • Exemplos:
  • CPU
  • RAM
  • HD
  • SSD
  • placa-mãe
⚠️ Pegadinha de banca:

A banca pode afirmar:

"Windows é um hardware."

❌ Errado.

Windows é software.

CPU (Processador)

A CPU (Central Processing Unit) é considerada o cérebro do computador.

Ela é responsável por executar instruções e processar dados.

O processador realiza milhões ou bilhões de operações por segundo.

Componentes da CPU

A CPU possui dois componentes principais.

Unidade de Controle (UC)

Responsável por coordenar a execução das instruções.

Unidade Lógica e Aritmética (ULA)

Responsável por executar operações:

  • matemáticas
  • lógicas
📦 Resumo estratégico:

CPU é formada por:

🧠 Memorize:

CPU = UC + ULA

Ciclo de Processamento

O funcionamento do processador ocorre através de um ciclo chamado:

  • Ciclo de Instrução

Esse ciclo possui três etapas principais.

1️⃣ Fetch (Busca)

O processador busca a instrução na memória.

2️⃣ Decode (Decodificação)

A instrução é interpretada.

3️⃣ Execute (Execução)

A instrução é executada.

📦 Resumo estratégico:

Ciclo do processador:

Fetch → Decode → Execute

⚠️ Pegadinha de banca:

Algumas questões afirmam que o ciclo possui apenas duas etapas.

❌ Errado.

O ciclo possui três etapas.

Memória Cache

A memória Cache é uma memória extremamente rápida utilizada para armazenar dados frequentemente acessados pelo processador.

Ela serve para reduzir o tempo de acesso à memória RAM.

Níveis de Cache

Existem três níveis principais.

📦 Resumo estratégico:

Velocidade das memórias:

Cache > RAM > SSD > HD

⚠️ Pegadinha de banca:

A banca pode afirmar:

"Cache é mais lenta que RAM."

❌ Errado.

Cache é mais rápida que RAM.

Memória RAM

A RAM (Random Access Memory) é a memória utilizada para armazenar dados temporários enquanto os programas estão em execução.

Características:

  • memória volátil
  • alta velocidade
  • dados são apagados ao desligar o computador
📦 Resumo estratégico:

RAM = memória temporária

Memória ROM

A ROM (Read Only Memory) é uma memória não volátil.

Ela armazena informações permanentes do sistema.

Exemplo:

  • firmware
  • BIOS

RAM vs ROM

⚠️ Pegadinha de banca:

RAM não é permanente.

Ela perde os dados quando o computador é desligado.

Dispositivos de Armazenamento

Os dispositivos de armazenamento são utilizados para guardar dados permanentemente.

Os principais são:

  • HD (HDD)
  • SSD

HD (Hard Disk)

O HD utiliza discos magnéticos para armazenar dados.

Características:

  • partes mecânicas
  • menor velocidade
  • maior capacidade
  • menor custo

SSD (Solid State Drive)

O SSD utiliza memória flash para armazenar dados.

Características:

  • maior velocidade
  • sem partes mecânicas
  • menor tempo de acesso

Tipos de SSD

SSD SATA

Utiliza interface SATA.

Velocidade média:

  • até 600 MB/s
  • SSD NVMe

Utiliza interface PCIe.

Velocidade muito maior.

Pode ultrapassar:

  • 3000 MB/s

SSD vs HD

⚠️ Pegadinha de banca:

Algumas provas afirmam:

"SSD é um disco magnético."

❌ Errado.

SSD usa memória flash.

🧠 Memorize:

Armazenamento do mais rápido para o mais lento:

Cache → RAM → SSD → HD

Placa-mãe

A placa-mãe é o componente responsável por conectar todos os dispositivos do computador.

Ela permite a comunicação entre:

  • CPU
  • memória
  • dispositivos de armazenamento
  • periféricos

Componentes importantes da placa-mãe

chipset

slots de memória

conectores SATA

slots PCIe

📦 Resumo estratégico:

Placa-mãe = central de conexão do computador
