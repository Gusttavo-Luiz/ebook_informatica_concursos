Conceito de Sistema Operacional

O Sistema Operacional (SO) é o software responsável por gerenciar todos os recursos do computador e permitir a interação entre:

  • hardware
  • softwares aplicativos
  • usuário

Sem um sistema operacional, o computador não conseguiria executar programas.

Exemplos de sistemas operacionais:

  • Windows 10 / Windows 11

Linux (Ubuntu, Debian, Fedora)

macOS

Principais funções do Sistema Operacional

O sistema operacional possui várias responsabilidades fundamentais.

Gerenciamento de Processos

Controla a execução dos programas.

Exemplo:

  • abrir navegador
  • executar editor de texto
  • executar planilhas

Gerenciamento de Memória

Controla o uso da memória RAM pelos programas.

Isso evita que um programa utilize toda a memória do sistema.

Gerenciamento de Arquivos

Organiza dados em:

  • arquivos
  • pastas
  • diretórios

Controle de Dispositivos

Gerencia periféricos como:

  • teclado
  • mouse
  • impressora
  • monitor

Pegadinha de banca
  • Muitas provas afirmam:
  • "O sistema operacional é um hardware."
  • ❌ Errado

O sistema operacional é um software de sistema.

Memorize

Tipos de software:

Kernel

O Kernel é o núcleo do sistema operacional.

Ele é responsável por realizar a comunicação direta com o hardware.

Principais funções do Kernel:

  • controle de processos
  • gerenciamento de memória
  • controle de dispositivos
  • gerenciamento de interrupções

Tipos de Kernel

Kernel Monolítico

Todos os serviços do sistema estão integrados no núcleo.

Exemplo:

  • Linux
  • Microkernel

O núcleo possui apenas funções essenciais.

Outros serviços são executados separadamente.

Exemplo:

  • Minix
Resumo estratégico
Pegadinha de banca
  • A banca costuma afirmar:
  • "O kernel é responsável pela interface gráfica."
  • ❌ Errado

A interface gráfica pertence ao ambiente gráfico, não ao kernel.

Sistemas de Arquivos

Os sistemas de arquivos definem como os dados são armazenados no disco.

NTFS

Sistema de arquivos padrão do Windows.

Características:

  • suporte a permissões
  • criptografia
  • compressão
  • journaling
  • FAT32

Sistema de arquivos antigo.

Características:

  • compatível com vários sistemas
  • limite de arquivos de 4 GB
  • EXT4

Sistema de arquivos utilizado no Linux.

Características:

  • journaling
  • maior desempenho
  • melhor gerenciamento de arquivos grandes

Comparação entre Sistemas de Arquivos

Pegadinha de banca

Pergunta comum:

Qual sistema de arquivos é utilizado pelo Linux?

Resposta correta:

➡ EXT4

Permissões no Linux

O Linux possui um sistema de permissões baseado em três tipos de acesso.

Essas permissões são aplicadas para:

  • usuário
  • grupo
  • outros
  • Comando chmod

O comando chmod altera permissões de arquivos.

Exemplo:

  • chmod 755 arquivo
  • Significado:

7 = leitura + escrita + execução

5 = leitura + execução

Memorize

Valores das permissões:

Exemplo:

7 = 4 + 2 + 1

Windows 10 / 11

Linux (Ubuntu / Debian)

Características:

  • código aberto
