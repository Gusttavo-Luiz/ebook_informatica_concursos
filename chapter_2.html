Conceito de sistema operacional

O sistema operacional (SO) é o software básico que gerencia os recursos do computador e serve de intermediário entre o hardware, os aplicativos e o usuário.

Sem um sistema operacional, cada programa precisaria saber controlar diretamente o processador, a memória, o disco e cada periférico. O SO esconde essa complexidade e oferece uma base comum para todos os aplicativos.

Exemplos de sistemas operacionais:

  • Computadores: Windows 10 e 11, macOS, distribuições Linux (Ubuntu, Debian, Fedora, Linux Mint).
  • Dispositivos móveis: Android (baseado no kernel Linux) e iOS.
  • Servidores: Windows Server e distribuições Linux como Red Hat Enterprise Linux e Debian.
Pegadinha de banca

“O sistema operacional é um hardware.” Errado: ele é um software básico (de sistema). Também é errado dizer que o SO é um aplicativo.

Funções do sistema operacional

FunçãoO que faz

Gerência de memóriadistribui a RAM entre os programas e impede que um invada a área do outro
Gerência de arquivosorganiza dados em arquivos e pastas (diretórios) no disco
Gerência de dispositivos (E/S)controla periféricos por meio de drivers
Segurança e usuárioscontas, senhas, permissões de acesso

Conceitos ligados aos processos

  • Processo: um programa em execução.
  • Multitarefa: vários programas executando “ao mesmo tempo”. O SO alterna o processador entre eles tão rápido que parece simultâneo.
  • Multitarefa preemptiva: o SO pode interromper um programa para dar a vez a outro. É o modelo dos sistemas atuais.
  • Multiusuário: várias contas de usuário com arquivos e permissões separados.
  • Memória virtual: quando a RAM acaba, o SO usa parte do disco como extensão da memória (arquivo de paginação no Windows, área de swap no Linux). Funciona, mas é bem mais lento.
  • Driver: software que permite ao SO controlar um dispositivo específico, como uma impressora.
Resumo estratégico

O SO gerencia quatro grandes recursos: processador (processos), memória, arquivos e dispositivos de entrada e saída.

Kernel

O kernel (núcleo) é a parte central do sistema operacional. Ele roda com privilégio máximo e se comunica diretamente com o hardware, cuidando do controle de processos, da memória, dos dispositivos e das interrupções.

Tipo de kernelCaracterísticaExemplo
Monolíticoquase todos os serviços rodam dentro do núcleo; é rápido, mas uma falha pode derrubar o sistemaLinux
Microkernelo núcleo tem só o essencial; os demais serviços rodam separados; é mais modular e estávelMinix
Híbridomistura as duas abordagensWindows (NT) e macOS (XNU)
Pegadinha de banca

“O kernel é responsável pela interface gráfica.” Errado: a interface gráfica é um programa que roda sobre o kernel. Também é comum a banca afirmar que “Linux” é o sistema completo; tecnicamente, Linux é o kernel, e o sistema completo é uma distribuição.

Interface gráfica e linha de comando

  • GUI (Graphical User Interface): janelas, ícones, menus e botões. Exemplos no Linux: GNOME, KDE Plasma, XFCE e Cinnamon.
  • CLI (Command Line Interface): o usuário digita comandos em um interpretador, o shell. Exemplos: Bash (Linux), Prompt de Comando e PowerShell (Windows).

Sistemas de arquivos

O sistema de arquivos define como os dados são organizados, nomeados e protegidos no disco.

SistemaUso típicoCaracterísticas
NTFSpadrão do Windowspermissões, criptografia, compressão, cotas e journaling
FAT32pen drives e cartões antigoscompatível com quase tudo, mas limita cada arquivo a 4 GB
exFATpen drives e cartões de memória atuaiscompatível com Windows e macOS, sem o limite de 4 GB por arquivo
ext4padrão em muitas distribuições Linuxjournaling, bom desempenho e suporte a arquivos grandes
APFSmacOS e iOSotimizado para SSD, com criptografia nativa

Journaling é um registro das alterações pendentes: se o computador desligar no meio de uma gravação, o sistema consegue recuperar a consistência do disco.

Pegadinha de banca

Um arquivo de vídeo de 5 GB não pode ser copiado para um pen drive formatado em FAT32, mesmo que haja espaço livre. A solução é formatar em exFAT ou NTFS.

Windows

Componentes mais cobrados

  • Explorador de Arquivos: gerencia pastas e arquivos. Atalho: Windows + E.
  • Área de Trabalho, Barra de Tarefas e Menu Iniciar.
  • Configurações e Painel de Controle: ajustes do sistema, contas, rede e aplicativos.
  • Gerenciador de Tarefas: mostra processos, desempenho e programas que iniciam com o Windows. Atalho: Ctrl + Shift + Esc.
  • Lixeira: guarda temporariamente os arquivos excluídos do disco local, permitindo restaurá-los.

Lixeira

  • Delete envia o arquivo para a Lixeira.
  • Shift + Delete exclui permanentemente, sem passar pela Lixeira.
  • Arquivos apagados de pen drives, cartões de memória e pastas de rede não vão para a Lixeira: são excluídos direto.
  • Arquivos maiores que o espaço reservado para a Lixeira também são excluídos permanentemente (o Windows avisa antes).
Pegadinha de banca

“Todo arquivo excluído no Windows pode ser recuperado pela Lixeira.” Errado: exclusões com Shift + Delete e as feitas em unidades removíveis ou de rede não passam por ela.

Extensões de arquivo

A extensão indica o tipo do arquivo e qual programa o abre: .exe (executável), .txt (texto simples), .docx (Word), .xlsx (Excel), .pdf, .jpg e .png (imagens), .mp3 (áudio), .mp4 (vídeo), .zip (compactado).

Linux

O Linux é um kernel de código aberto criado por Linus Torvalds em 1991 e distribuído sob a licença GPL. Ele é combinado com ferramentas do projeto GNU e outros programas para formar as distribuições (Ubuntu, Debian, Fedora, Mint, Red Hat).

  • É multiusuário e multitarefa.
  • Diferencia letras maiúsculas de minúsculas: Relatorio.txt e relatorio.txt são arquivos diferentes.
  • O superusuário (administrador) se chama root. O comando sudo executa um comando com privilégios de administrador.
  • Domina o mercado de servidores e é a base do Android.

Pegadinha de banca

Não confunda / (raiz do sistema) com /root (pasta pessoal do administrador).

Permissões no Linux

Cada arquivo tem três tipos de permissão, aplicados a três grupos de pessoas.

PermissãoLetraValor
Leitura (read)r4
Escrita (write)w2
Execução (execute)x1

As permissões são definidas, nesta ordem, para o dono (usuário), o grupo e os outros. Somando os valores, cada grupo recebe um dígito de 0 a 7.

Exemplo — chmod 754 relatorio.sh

dono   = 7 = 4 + 2 + 1 = rwx  (ler, escrever e executar)
grupo  = 5 = 4 + 0 + 1 = r-x  (ler e executar)
outros = 4 = 4 + 0 + 0 = r--  (apenas ler)

ls -l mostra:  -rwxr-xr--  relatorio.sh
Memorize

r = 4, w = 2, x = 1. Os valores mais comuns: 7 (rwx), 6 (rw-), 5 (r-x), 4 (r--) e 0 (---). A ordem dos dígitos é sempre dono, grupo, outros.
