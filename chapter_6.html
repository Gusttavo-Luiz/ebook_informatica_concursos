Conceito de Computação em Nuvem

A computação em nuvem (Cloud Computing) é um modelo de tecnologia que permite o acesso a dados, softwares e recursos computacionais através da internet.

Em vez de armazenar arquivos apenas no computador local, os dados são armazenados em servidores remotos mantidos por empresas especializadas.

Esses dados podem ser acessados de qualquer lugar, desde que exista conexão com a internet.

Exemplos de serviços em nuvem:

  • Google Drive
  • Microsoft OneDrive
  • Apple iCloud
  • Dropbox

Amazon Web Services (AWS)

  • sincronização entre dispositivos

Modelos de Serviço em Nuvem

A computação em nuvem é dividida em três principais modelos de serviço.

IaaS (Infrastructure as a Service)

Nesse modelo, o provedor oferece infraestrutura de computação.

Inclui:

  • servidores virtuais
  • armazenamento
  • redes

O usuário gerencia o sistema operacional e os aplicativos.

Exemplo:

  • Amazon EC2

PaaS (Platform as a Service)

Nesse modelo, o provedor oferece uma plataforma completa para desenvolvimento de aplicações.

Inclui:

  • sistema operacional
  • ambiente de desenvolvimento
  • banco de dados
  • Exemplo:

Google App Engine

SaaS (Software as a Service)

Nesse modelo, o usuário acessa aplicações prontas através da internet.

Não é necessário instalar software no computador.

Exemplos:

  • Google Docs
  • Microsoft 365
  • Gmail

Comparação dos Modelos de Nuvem

Resposta:

➡ SaaS

Sincronização de Arquivos

Um dos recursos mais importantes da computação em nuvem é a sincronização de arquivos.

Isso significa que os arquivos são automaticamente atualizados entre:

  • computador
  • smartphone
  • tablet
  • servidores da nuvem
  • Exemplo:

Se um arquivo for editado no computador, ele será atualizado automaticamente no smartphone.

📦 Resumo estratégico:
  • Sincronização garante:
  • atualização automática dos arquivos
  • acesso em múltiplos dispositivos

Google Drive

O Google Drive é um serviço de armazenamento em nuvem desenvolvido pela Google.

Ele permite:

  • armazenar arquivos
  • compartilhar documentos
  • editar arquivos online

Ferramentas integradas

Google Sheets

Características

Microsoft OneDrive

O OneDrive é o serviço de nuvem da Microsoft.

Ele é integrado ao sistema operacional Windows 10 e Windows 11.

Principais recursos

sincronização automática com o Windows

integração com Microsoft Office

compartilhamento de arquivos

Apple iCloud

O iCloud é o serviço de armazenamento em nuvem da Apple.

Ele é utilizado principalmente em dispositivos:

  • iPad
  • Mac

Principais medidas de segurança incluem:

  • controle de acesso
