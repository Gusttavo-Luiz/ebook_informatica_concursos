O Pacote Office é um conjunto de aplicativos de produtividade utilizados para criação, edição e organização de documentos.

Esses aplicativos são amplamente utilizados em ambientes corporativos e administrativos.

Microsoft Word

O Microsoft Word é um editor de texto utilizado para criação de documentos como:

  • relatórios
  • cartas
  • trabalhos acadêmicos
  • documentos administrativos

Recursos de Formatação

O Word permite alterar diversos aspectos do texto.

Formatação de Fonte

Formatação de Parágrafo

Principais configurações:

  • alinhamento
  • espaçamento
  • recuo
  • listas

Microsoft Excel

O Microsoft Excel é um software de planilhas eletrônicas utilizado para:

  • cálculos
  • análise de dados
  • relatórios financeiros
  • controle administrativo

Ele organiza dados em:

  • linhas
  • colunas
  • células

Estrutura da Planilha

Exemplo:

  • A1

Fórmulas no Excel

As fórmulas sempre começam com o símbolo:

  • =
  • Exemplo:
  • =A1+B1

Funções Importantes do Excel

As funções são fórmulas pré-definidas que realizam cálculos automaticamente.

PROCV (VLOOKUP)

A função PROCV é usada para buscar valores em uma tabela.

Sintaxe:

  • =PROCV(valor_procurado; tabela; coluna; FALSO)
  • Exemplo:

Buscar o preço de um produto em uma tabela.

📦 Resumo estratégico:

PROCV significa:

➡ Procurar Verticalmente

⚠️ Pegadinha de banca:

O PROCV sempre procura na primeira coluna da tabela.

Função SE

A função SE realiza testes lógicos.

  • Sintaxe:
  • =SE(teste_lógico; valor_se_verdadeiro; valor_se_falso)
  • Exemplo:
  • =SE(A1>=7;"Aprovado";"Reprovado")
📦 Resumo estratégico:
  • Função SE permite:
  • tomada de decisão na planilha
  • Função CONT.SE

Conta quantas células atendem um determinado critério.

  • Sintaxe:
  • =CONT.SE(intervalo; critério)
  • Exemplo:

Contar alunos aprovados.

Função SOMASE

Soma valores que atendem um critério.

Sintaxe:

=SOMASE(intervalo; critério; intervalo_soma)

🧠 Memorize:
  • Funções muito cobradas:
  • PROCV
  • SE
  • CONT.SE
  • SOMASE

Microsoft PowerPoint

O PowerPoint é utilizado para criar apresentações.

É muito utilizado em:

  • reuniões
  • aulas
  • apresentações empresariais

Estrutura de uma Apresentação

Uma apresentação é formada por slides.

Cada slide pode conter:

  • textos
  • imagens
  • gráficos
  • vídeos

Recursos Importantes

Transições

Controlam a passagem de um slide para outro.

Animações

Aplicadas a elementos dentro do slide.

Temas

Conjuntos de estilos visuais aplicados à apresentação.

📦 Resumo estratégico:

PowerPoint trabalha com:

➡ slides
