Conceito de Segurança da Informação

A Segurança da Informação é o conjunto de práticas, políticas e tecnologias utilizadas para proteger informações contra:

  • acesso não autorizado
  • alteração indevida
  • destruição de dados
  • indisponibilidade de sistemas

O objetivo é garantir que as informações permaneçam seguras e confiáveis.

📦 Resumo estratégico:
  • Segurança da Informação protege dados contra:
  • acesso indevido
  • alteração indevida
  • perda de disponibilidade
⚠️ Pegadinha de banca:

A banca pode afirmar:

"Segurança da informação protege apenas dados digitais."

❌ Errado.

Ela protege qualquer tipo de informação, inclusive documentos físicos.

Princípios da Segurança da Informação

Os princípios da segurança da informação são conhecidos como modelo CIA.

CIA significa:

  • Confidencialidade
  • Integridade
  • Disponibilidade
  • Confidencialidade

Garante que apenas usuários autorizados tenham acesso às informações.

Exemplo:

  • senhas
  • criptografia
  • controle de acesso
  • Integridade

Garante que os dados não sejam alterados indevidamente.

Exemplo:

  • assinatura digital
  • hash
  • Disponibilidade

Garante que os sistemas e dados estejam acessíveis quando necessários.

Exemplo:

  • redundância de servidores
  • backup
📦 Resumo estratégico:

Modelo clássico:

CIA

🧠 Memorize:
  • CIA
  • Confidencialidade
  • Integridade

Acesso (disponibilidade)

Princípios Estendidos da Segurança

Além do modelo CIA, existem princípios adicionais.

Autenticidade

Garante que a identidade do usuário seja verdadeira.

Exemplo:

  • login e senha
  • autenticação em dois fatores
  • Não Repúdio

Impede que um usuário negue uma ação realizada.

Exemplo:

  • assinatura digital

Tipos de Malware

Malware é qualquer software malicioso criado para prejudicar sistemas ou roubar informações.

A palavra malware vem de:

  • Malicious Software
  • Vírus

Programa que se replica infectando outros arquivos.

Pode causar:

  • corrupção de dados
  • danos ao sistema
  • Worm

Programa que se espalha automaticamente pela rede.

Não precisa infectar arquivos.

Trojan (Cavalo de Troia)

Programa malicioso que se disfarça de software legítimo.

Exemplo:

  • aplicativos falsos
  • downloads maliciosos
  • Ransomware

Malware que sequestra arquivos do usuário.

O criminoso exige pagamento para liberar os dados.

Spyware

Software que espiona atividades do usuário.

Pode coletar:

  • senhas
  • dados pessoais
  • hábitos de navegação
  • Rootkit

Malware que esconde sua presença no sistema.

Ele permite que invasores tenham acesso remoto ao computador.

📦 Resumo estratégico:
  • Principais tipos de malware:
  • vírus
  • worm
  • trojan
  • ransomware
  • spyware
  • rootkit
⚠️ Pegadinha de banca:

A banca costuma confundir:

Phishing ≠ Malware

Phishing é engenharia social, não um software.

Ferramentas de Proteção

Para proteger sistemas contra ataques, existem diversas ferramentas.

Antivírus

Software responsável por detectar e remover malwares.

Exemplos:

  • Windows Defender
  • Kaspersky
  • Avast
  • Firewall

Sistema que controla o tráfego de rede.

Ele permite ou bloqueia conexões de acordo com regras de segurança.

📦 Resumo estratégico:

Firewall:

➡ controla tráfego de rede

IDS (Intrusion Detection System)

Sistema de detecção de intrusão.

Ele monitora atividades suspeitas na rede.

Backup

Cópia de segurança dos dados.

Permite recuperar informações em caso de perda ou ataque.

Ferramentas de Segurança

  • Proteção básica de sistemas:
  • AFIB

Engenharia Social

A engenharia social consiste em manipular pessoas para obter informações sensíveis.

Exemplos:

  • phishing
  • e-mails falsos
  • páginas falsas
  • Phishing

Golpe que tenta roubar informações do usuário.

Normalmente utiliza:

  • e-mails falsos
  • páginas falsas de banco
⚠️ Pegadinha de banca:

Phishing não invade sistemas.

Ele engana o usuário para que ele forneça informações.
