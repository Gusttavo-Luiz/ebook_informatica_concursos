Conceito de Internet

A Internet é uma rede mundial de computadores interconectados que utilizam o conjunto de protocolos TCP/IP para comunicação.

Ela permite a troca de informações entre dispositivos localizados em qualquer parte do mundo.

Entre os principais serviços da internet estão:

  • navegação em páginas web
  • correio eletrônico (e-mail)
  • transferência de arquivos
  • comunicação em tempo real
  • computação em nuvem
Resumo estratégico

Internet é baseada no protocolo:

➡ TCP/IP

Esse conjunto de protocolos permite a comunicação entre computadores em redes diferentes.

Pegadinha de banca

Algumas provas afirmam:

"HTTP é o protocolo responsável por identificar computadores na internet."

❌ Errado

Quem identifica computadores é o IP (Internet Protocol).

Modelo OSI

O Modelo OSI (Open Systems Interconnection) é um modelo conceitual utilizado para entender o funcionamento das redes de computadores.

Ele divide a comunicação em 7 camadas.

Resumo estratégico
  • Camadas do modelo OSI:
  • Física
  • Enlace
  • Rede
  • Transporte
  • Sessão
  • Apresentação
  • Aplicação

Endereçamento IP

Cada dispositivo conectado à rede possui um endereço IP.

Esse endereço identifica o dispositivo na rede.

IPv4

Formato:

  • 192.168.0.1
  • Características:
  • 32 bits
  • cerca de 4 bilhões de endereços
  • IPv6
  • Formato:

2001:0db8:85a3:0000:0000:8a2e:0370:7334

Características:

  • 128 bits
  • número muito maior de endereços
Resumo estratégico
Pegadinha de banca

Algumas questões afirmam:

"IPv6 foi criado para substituir o TCP."

❌ Errado.

IPv6 substitui IPv4, não TCP.

DNS (Domain Name System)

O DNS é o sistema responsável por traduzir nomes de domínio em endereços IP.

Exemplo:

  • www.google.com → 142.250.190.78

Sem DNS, seria necessário acessar os sites digitando o IP.

Resumo estratégico
  • DNS significa:
  • Domain Name System
  • Função:
  • traduz nome de domínio em IP

Utiliza criptografia SSL/TLS.

FTP

Navegadores (Browsers)

Os navegadores são programas utilizados para acessar páginas da web.

Principais navegadores:

  • Google Chrome
  • Microsoft Edge
  • Mozilla Firefox
  • Safari

Funcionalidades dos Navegadores

Entre as funcionalidades estão:

  • navegação por abas
  • histórico de navegação
  • favoritos
  • extensões

Mecanismos de Busca

Motores de busca permitem encontrar informações na internet.

Exemplos:

  • Google
  • Bing
  • DuckDuckGo
Resumo estratégico

Navegador ≠ mecanismo de busca.

Pegadinha de banca

Pergunta comum:

"Google é um navegador."

❌ Errado.

Google é mecanismo de busca.

O navegador é Chrome.
